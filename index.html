Pertanyaan Umum (FAQ)

Beberapa jawaban cepat seputar jasa pembuatan aplikasi software dan pemasangan CCTV.

Berapa lama waktu pembuatan custom software/aplikasi?
Waktu pengerjaan bergantung pada kompleksitas modul dan fitur. Halaman web company profile standar membutuhkan waktu 1-2 minggu. Sedangkan sistem custom seperti web ERP pergudangan, aplikasi mobile iOS/Android, berkisar antara 1 hingga 3 bulan pengerjaan terhitung setelah persetujuan dokumen spesifikasi sistem (SRS).
Apakah saya akan mendapatkan kepemilikan source code secara penuh?
Ya. Setelah pengerjaan aplikasi dinyatakan selesai (UAT disetujui) dan dilakukan pelunasan biaya proyek, seluruh kode program (source code) dan kredensial hosting/cloud server akan diserahkan sepenuhnya kepada pihak pelanggan. Sinergi Solusi Digital tidak mengenakan biaya royalti atau sewa lisensi tahunan untuk software custom.
Apakah ada garansi maintenance untuk aplikasi software yang dibuat?
Tentu saja. Kami memberikan masa garansi pemeliharaan (maintenance) bug-free gratis selama 3 bulan setelah aplikasi go-live. Layanan ini mencakup perbaikan eror sistem, optimasi database, dan monitoring keamanan server. Setelah 3 bulan, Anda dapat memperpanjang kontrak maintenance tahunan bersama kami.
Apakah CCTV bisa dipantau lewat HP secara online gratis?
Sangat bisa! Teknisi kami akan membantu melakukan konfigurasi setting online ke jaringan internet/Wi-Fi di lokasi Anda, dan memasangkan aplikasinya di HP Android atau iOS Anda. Pemantauan live maupun play rekaman tidak dikenakan biaya bulanan.
